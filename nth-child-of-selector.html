Count only the rows that count.

:nth-child(An+B of S) counts only the siblings that match S, and skips the rest. Zebra stripes stay correct when a filter hides rows — no JS pass that re-adds an .odd class after every change.

01 / PLAIN STRIPES

:nth-child(even)

The classic zebra table. Every second row gets the stripe. This works fine while every row is on screen.

Applefruit
Bananafruit
Carrotveg
Pearfruit
Leekveg
Kaleveg
 
tr:nth-child(even) {
  background: var(--stripe);
}

02 / THE BREAK — interactive

Hidden rows still count

Pick a filter. It sets hidden on the rows that don't match. :nth-child(even) still counts those hidden rows, so the stripes now land on the wrong rows — two shaded rows touch, or none. 

tr:nth-child(even) {
  background: var(--stripe);
}
/* counts every <tr>, including the [hidden] ones */

03 / OF S — interactive

:nth-child(even of :not([hidden]))

Add of S and the count only includes rows that match S. Hidden rows drop out of the count, so the visible rows always alternate. Change the filter and compare the two tables.

:nth-child(even)
:nth-child(even of :not([hidden])) 
tr:nth-child(even of :not([hidden])) {
  background: var(--stripe);
}
/* S can be any selector list — :not([hidden]), .visible, [aria-selected] … */

04 / FIRST OF A CLASS

:nth-child(1 of .featured)

.featured:first-of-type looks like it should pick the first featured item, but -of-type means the tag name, not the class — here it matches nothing. 1 of .featured picks the first .featured item, wherever it sits.

  • Plain card li
  • First featured card li.featured ← matched
  • Plain card li
  • Featured card li.featured
  • Featured card li.featured
li:nth-child(1 of .featured) {
  border-color: var(--accent);
}
/* .featured:first-of-type → no match: the first <li> isn't .featured */

05 / FROM THE END

:nth-last-child(-n + 2 of .done)

of S works on :nth-last-child() too. Here it marks the two most recent finished tasks — the last two .done items — and ignores the open tasks in between.

  • Draft outline .done
  • Write intro .done
  • Build demo .done ← matched
  • Review copy open
  • Fix typos .done ← matched
  • Publish open
li:nth-last-child(-n + 2 of .done) {
  border-color: var(--accent-3);
}
/* -n + 2 → the last 2 matches, counted from the end */
