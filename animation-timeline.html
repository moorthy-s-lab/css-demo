Time, measured in scroll.

animation-timeline swaps clock time for scroll or visibility progress. Pair it with animation-range to say exactly which part of that journey maps to 0–100%—without a scroll listener updating styles frame by frame.

Scroll-driven syntax map

Attach a timeline to an animation

animation-timeline: auto | none | --name | scroll(…) | view(…) [, …];

auto is normal clock time; none detaches the animation. Commas map timelines to multiple animation names.

Anonymous scroll timeline

animation-timeline: scroll([scroller || axis]);

scroller: nearest | root | self
axis: block | inline | x | y
Examples: scroll(), scroll(root block), scroll(x self). Arguments may appear in either order; default is nearest block.

Anonymous view timeline

animation-timeline: view([axis || inset{1,2}]);

axis: block | inline | x | y
inset: auto | <length-percentage>
Examples: view(), view(inline), view(block 20% 40%), view(x 200px auto). Default is block auto.

Create named timelines

scroll-timeline: --name [axis];
view-timeline: --name [axis || inset{1,2}];

Put the name first. Longhands: *-timeline-name, *-timeline-axis, and view-timeline-inset. Consume either source with animation-timeline: --name.

Widen a named timeline's reach

timeline-scope: none | all | --name [, --other];

Set it on a common ancestor when the source and animation are siblings or cousins. It applies only to named timelines—not scroll() or view().

Trim the attachment range

animation-range: <start> [<end>] [, …];
<point> = normal | <length-percentage> | <range-name> [<length-percentage>]

range names: cover | contain | entry | exit | entry-crossing | exit-crossing | scroll. Examples: entry, 25% 75%, entry 20% exit 80%. Longhands: animation-range-start and animation-range-end.

Order matters: declare the animation shorthand first because it resets animation-timeline. Then attach the timeline and, if needed, set animation-range.
