Paint text without touching the DOM.

  • Mark any text with a Range in JS.
  • Style it with ::highlight(name) in CSS.
  • No <span> or <mark> wrappers — the DOM stays untouched.

01 / BASICS — interactive

A range, a highlight, a pseudo-element

  • new Range() → pick the text (a start and an end offset).
  • new Highlight(range) → group it.
  • CSS.highlights.set(name, …) → name it.
  • ::highlight(name) → style it.
  • Try it: select words with your mouse, or drag the start / end sliders.
  • The highlight stays after you click away — unlike the native selection.

A range points at a character offset where it starts and another where it ends, and everything between them can be painted.

start 0 · end 0 · range.toString() → ""

const text  = document.querySelector('#d0').firstChild;  // the text node
const range = new Range();
range.setStart(text, start);   // character offset
range.setEnd(text, end);
CSS.highlights.set('d0-pick', new Highlight(range));

// mouse selection → copy its range into the highlight
document.addEventListener('selectionchange', () => {
  const sel = getSelection();
  if (sel.isCollapsed) return;
  const r = sel.getRangeAt(0);
  if (r.startContainer === text && r.endContainer === text)
    CSS.highlights.set('d0-pick', new Highlight(r.cloneRange()));
});

/* CSS */
::highlight(d0-pick) {
  background-color: var(--accent-3);
  color: var(--paper);
}

// Helper for the demos below: a Range over `word` in text node `node`,
// searching from offset `from`. Returns null if not found.
function rangeOf(node, word, from = 0) {
  const start = node.data.toLowerCase().indexOf(word.toLowerCase(), from);
  if (start === -1) return null;
  const range = new Range();
  range.setStart(node, start);
  range.setEnd(node, start + word.length);
  return range;
}

02 / SEARCH — interactive

Find-in-page, one highlight, many ranges

  • Each match = one Range.
  • All matches share one Highlight.
  • Ranges can cross element boundaries (see the bold text).
  • Element count stays the same — nothing is inserted.

A range marks a start and an end inside the document. A highlight can hold many ranges at once, and a range can cross element boundaries — like this one, which passes through bold text and back out again. Search engines, spell checkers and collaborative editors all need to paint ranges without rearranging the markup underneath.

matches 0 · elements in paragraph 0

// rangeOf() is the helper from 01
const box   = document.querySelector('#d2');    // text to search
const input = document.querySelector('#d2-q');  // search box

input.addEventListener('input', () => {
  const q = input.value;                        // search word
  const ranges = [];

  // visit every text node inside the box
  const walker = document.createTreeWalker(box, NodeFilter.SHOW_TEXT);
  while (q && walker.nextNode()) {
    const node = walker.currentNode;
    let r = rangeOf(node, q);
    while (r) {                                 // one Range per match
      ranges.push(r);
      r = rangeOf(node, q, r.endOffset);        // look after this match
    }
  }

  // one Highlight holds every match
  CSS.highlights.set('d2-search', new Highlight(...ranges));
});

/* CSS */
::highlight(d2-search) {
  background-color: var(--accent-2);
  color: var(--paper);
}

03 / ALLOWED PROPERTIES

Paint only, never layout

  • ✓ Paint properties: color, background-color, text-decoration, text-shadow.
  • ✗ Layout properties: font-weight, padding — silently ignored.
  • Why: a highlight can't move or resize text.

/* CSS */

::highlight(d3-deco)    { text-decoration: underline 3px var(--accent-2); }
::highlight(d3-shadow)  { text-shadow: 0 0 6px var(--accent-3); }

/* not paint properties — dropped without warning */
::highlight(d3-weight)  { font-weight: 900; }
::highlight(d3-padding) { padding: 0 20px; }

04 / PRIORITY — interactive

When two highlights overlap

  • A and B overlap in the middle.
  • Higher priority paints on top.
  • Tie → the one registered last wins (B).
  • Drag B's priority below 0 to put A on top.

Two separate tools have claimed the same stretch of words in this sentence.

A · priority 0 B · priority 0 on top: B 
// rangeOf() is the helper from 01
const text = document.querySelector('#d4').firstChild;
const a = new Highlight(rangeOf(text, 'separate tools have claimed the same'));
const b = new Highlight(rangeOf(text, 'claimed the same stretch of words'));

CSS.highlights.set('d4-a', a);
CSS.highlights.set('d4-b', b);  // registered last → wins ties

b.priority = -1;                 // now A paints over B

05 / TYPE

Telling tools what a highlight means

  • type gives a highlight a meaning.
  • Values: "highlight" (default), "spelling-error", "grammar-error".
  • Screen readers can announce it, like native spell-check.
  • It does not add any style — the wavy lines come from CSS.

The reciept was left on the table, and the guests has already gone home.

type: "spelling-error" type: "grammar-error" 
// rangeOf() is the helper from 01
const text = document.querySelector('#d5').firstChild;

const spell = new Highlight(rangeOf(text, 'reciept'));
spell.type = 'spelling-error';

const grammar = new Highlight(rangeOf(text, 'guests has'));
grammar.type = 'grammar-error';

CSS.highlights.set('d5-spell', spell);
CSS.highlights.set('d5-grammar', grammar);

/* CSS */
::highlight(d5-spell) {
  text-decoration: wavy underline 1.5px var(--accent-2);
}

06 / LIVE RANGES — interactive

Ranges follow the text; static ranges don't

  • Range is live: it moves when text changes.
  • StaticRange is frozen: it stays at fixed offsets.
  • Try it: type at the start of each line.
Range
Type here → the target word moves.
StaticRange
Type here → the target word moves.
// rangeOf() is the helper from 01
const liveText   = document.querySelector('#d6-live').firstChild;
const staticText = document.querySelector('#d6-static').firstChild;

// Range — follows edits
const live = rangeOf(liveText, 'target');
CSS.highlights.set('d6-live', new Highlight(live));

// StaticRange — copy the offsets once, then they never change
const r = rangeOf(staticText, 'target');
const frozen = new StaticRange({
  startContainer: r.startContainer, startOffset: r.startOffset,
  endContainer:   r.endContainer,   endOffset:   r.endOffset,
});
CSS.highlights.set('d6-static', new Highlight(frozen));
