05 / The code

Three steps to draw

MAIN THREAD

const offscreen = canvas
  .transferControlToOffscreen();

// 2. Transfer ownership
worker.postMessage(offscreen,
  [offscreen]);

WORKER

// 3. Draw
onmessage = ({ data }) => {
  const ctx = data
    .getContext("2d");
  ctx.fillRect(0, 0, 100, 100);
};

07 / Independent canvas

Send the image back

Worker canvas→ImageBitmap→Page canvas

WORKER

const canvas = new OffscreenCanvas(600, 300);
const ctx = canvas.getContext("2d");
// Draw the moving square and background
const bitmap = canvas.transferToImageBitmap();
postMessage({ type: "frame", bitmap }, [bitmap]);

MAIN THREAD

worker.onmessage = ({ data }) => {
  if (data.type !== "frame") return;
  ctx.drawImage(data.bitmap, 0, 0);
  data.bitmap.close();
  worker.postMessage("next");
};

No connected canvas: transfer the image yourself.
