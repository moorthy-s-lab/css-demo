Lines that live in the gaps.

column-rule, row-rule, and the rule shorthand draw separators between grid and flex items — no per-item borders, no nth-child surgery. The container draws them.

01 / SHORTHAND BASICS — interactive

column-rule + row-rule

Add a normal gap, then style it. Drag the controls and watch the rules redraw. They never touch the layout — purely paint.

1

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
  /* the whole feature, two lines: */
  column-rule: 2px solid #2f4fd6;  /* between columns */
  row-rule:    2px solid #2f4fd6;  /* between rows    */
}
/* identical result with the universal shorthand: */
.grid { rule: 2px solid #2f4fd6; }

04 / INTERSECTIONS

rule-break

Where blue column rules cross orange row rules, rule-break decides what happens. normal breaks at T-junctions, intersection breaks at every crossing, none runs straight through.

normal

intersection

none

column-rule: 3px solid #2f4fd6;
row-rule:    3px solid #d9531e;
column-rule-break: intersection;  /* normal | intersection | none */

05 / INSET — interactive

rule-inset

Pull the rules inward from the ends of each gap so they don't run flush to the edges. Drag to see the segments shrink toward their centres. 

column-rule: 2px solid #2f4fd6;
row-rule:    2px solid #2f4fd6;
rule-inset: 8px;  /* shrink every rule 8px in from both ends */
